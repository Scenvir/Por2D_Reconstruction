# 自定义地图

将地图编辑器通过“保存地图 JSON”生成的 `.json` 文件放在此文件夹，然后启动游戏。地图会出现在关卡选择列表末尾，标记为“自定义”。无需导出 C++ 或重新编译。

地图必须为编辑器版本 1、50×30 格、每格 20 像素，包含有效的出生点和出口；标记身体不能越界或与墙重叠。无效文件会提示原因，不影响其他地图加载。

自定义关卡通关后显示完成，重开仍进入同一张地图。录制脚本会内嵌地图，因此即使原 JSON 文件移动或改名，录制仍能回放。

开发版 `build/Por2D.exe` 使用本文件夹。单独发布程序时，将 `levels` 文件夹放在 `Por2D.exe` 旁。
