# 自定义地图

在选关页点击“打开地图编辑器”（Ctrl+E），在默认浏览器中编辑。保存 JSON 或导出 C++ 会直接写入本文件夹，同名覆盖前会确认；请保持游戏运行。直接打开 HTML 时，需要支持目录选择的浏览器并选择游戏内的 levels 文件夹，否则请从游戏打开编辑器。

保存 JSON 后回到游戏点击“刷新列表”（F5）即可游玩，无需复制文件、重启或编译。“打开地图文件夹”（Ctrl+O）打开本文件夹，也可在这里手动放入其他 JSON。

所有地图统一从游戏的 levels 文件夹加载。刷新保留仍存在的选中地图，不改变当前正在玩的关卡或录制；要使用修改后的内容，请重新选择该地图开始。C++ 导出供开发使用，不显示在选关列表中。

地图必须为编辑器版本 1、50×30 格、每格 20 像素，包含有效的出生点和出口；标记身体不能越界或与墙重叠。无效文件会提示原因，不影响其他地图加载。

自定义关卡通关后显示完成，重开仍进入同一张地图。录制脚本会内嵌地图，因此即使原 JSON 文件移动或改名，录制仍能回放。

开发版 `build/Por2D.exe` 使用本文件夹。单独发布程序时，将 `levels` 文件夹放在 `Por2D.exe` 旁。
