# 回放目录

- [difficulty_review/](difficulty_review/README.md)：按当前菜单编号排列的 15 份代表性通关回放，`level00.txt` 至 `level14.txt` 与当前 Level 0–14 对应。每份脚本内的 `level` 使用源码地图 ID。
- [difficulty_review/verification.json](difficulty_review/verification.json)：当前版本逐份回放的结果及源码、脚本校验值。
- [difficulty_review/archive/2026-09-20/](difficulty_review/archive/2026-09-20/README.md)：整理前的完整快照，保留原文件、编号与验证记录，用于查阅历史难度分析。
- `level12_new_layout/route1.txt` 至 `route4.txt`：当前最终关 Level 14「天梯」的四条路线变体；目录名保留旧编号。当前索引采用 route1 作为代表路线。
- 其余旧的 `level12_*`：旧布局「天梯」的历史记录，不是当前地图的已验证解。

在菜单点击“回放”或按 F6 导入脚本。慢放使用设置里的运行速度。当前最终关通关输出 `replay=cleared level=16`，不会进入下一张地图。难度说明见 [关卡难度评估](../关卡难度评估.md)。
