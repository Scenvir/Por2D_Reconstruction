# Por2D · 基础重构版

本仓库 `Por2D_Reconstruction` 对应工作区目录 `por2_reconstructed/`，用于保留和整理固定向下重力的传送门玩法。[Por2D 四向重力版](https://github.com/Scenvir/Por2D) 则在此基础上加入 G 键切换重力；本版没有这一操作。两版都生成 `Por2D.exe`，可分别构建、分别游玩。

Por2D 是一款二维传送门解谜游戏。你控制一个淡黄色矩形角色，在白墙上放置相互连接的蓝门和橙门，利用传送改变位置、速度方向与身体朝向，最终以正确姿态抵达灰色出口，按 E 过关。

本版本的重力始终朝屏幕下方。解谜的关键不仅是到达出口，还包括利用传送门调整身体朝向、转换下落速度，以及在穿门过程中重新布置另一端。

第一次游玩请阅读 [新手教程](新手教程.md)。

## 游戏特色

- **位置、姿态与惯性解谜**：两扇门双向连通，身体和速度随门的方向变换；相同深浅的渐变位置彼此对应。
- **身体跨门操作**：角色可以同时露在两端。身体占比较大的一端会锁定并显示细金色边框，另一端在空间允许时仍可重新放置。
- **实时射门预览**：默认开启，按 Q 切换。蓝、橙箭头分别表示可放置的门，两种都能放时并列显示；绿色虚线和轮廓提示位置，两种都不能放时显示红色叉号。
- **中文关卡呈现**：15 个正式关卡配有中文名称和评语，入场时播放约 3 秒的短动画，可按任意键或点击鼠标跳过。
- **实时新手教学**：Level 0 入场后提供五段循环演示，使用实际游戏逻辑展示键位、墙面类型、中间格射击、头朝向与门朝向、跨门锁定。空格 / 右方向键继续，左方向键回看，也可跳过；教学场景不影响正式进度或录制。
- **菜单与帮助**：游戏右上角齿轮按钮打开暂停菜单；设置中的“帮助 / 新手教程”直接读取 `新手教程.md`，支持滚动阅读。单独发布程序时请将该文件放在 exe 旁。
- **便捷重试与选关**：默认 R 重开本关，Esc 暂停并打开独立菜单，包含继续游戏、设置、关卡选择和退出游戏。设置与选关期间保持暂停，返回菜单后可继续原进度。触碰地图任意边界会重开本关；死亡和 R 重试不重复播放入场动画。
- **自定义键位**：在菜单的“设置”里点击操作或用上下键选择、Enter 确认，再按新键。支持移动、跳跃、进入出口、重开、预览和两种传送门；传送门可绑定键盘或鼠标左右键，键盘发射时瞄准鼠标位置。重复键位提示冲突，Esc 取消改键，“恢复默认”重置全部键位。设置即时生效并保存到程序旁的 `keybindings.ini`，重启后加载；Esc、Enter、功能键等保留用于菜单和系统操作。以下操作表为默认键位，回放控制键保持固定。
- **原生 Windows 窗口**：支持窗口和等比例全屏显示，无需 EasyX。
- **显示设置**：全屏 / 窗口切换位于“设置”，也可使用 F11 或 Alt+Enter。尚未进入关卡时录制按钮置灰，不显示持续的选关提醒。
- **慢速运行**：设置中的“运行速度”可循环选择 0.1× 到 1.0×，每档 0.1×，并与键位一起保存。仅降低逻辑帧推进频率，每帧的物理计算、输入与回放指令不变；菜单和鼠标响应保持正常。回放只使用该全局倍率，没有独立慢速开关；单帧操作仍只推进一帧。
- **出口朝向**：灰色出口头部的深灰色小点与角色头部点位置、大小一致，表示通关要求的角色朝向。
- **JSON 地图**：将地图编辑器保存的 JSON 放入本目录的 `levels/` 后启动游戏，关卡选择末尾会显示“自定义”地图。附带 `levels/example.json` 示例；无需导出 C++ 或重新编译。无效地图会提示文件名与原因，其余地图照常加载。自定义地图通关后可重开同一关，录制会内嵌地图，回放不依赖原 JSON 文件。单独发布程序时将 `levels/` 放在 exe 旁。
- **菜单录制与回放**：录制、回放按钮在退出游戏上方左右并排，合计宽度与其他菜单按钮一致。回放按钮打开脚本选择窗口，等同 F6；录制从当前关卡起点开始，等同 F10。

## 开始游玩

已有构建产物时，双击本目录的 `build/Por2D.exe`。启动页播放随机演示，按空格跳过并进入主菜单，再进入关卡选择，从 **Level 0「概念」** 开始即可。实时教学支持 P 键或“暂停 / 继续”按钮；点击“亲自试试”可用当前键位练习，练习时用按钮暂停或换段。通关 Level 14 后永久解锁随头部旋转的金色皇冠，可在设置中隐藏，仅影响外观。皇冠解锁状态及显示偏好保存在程序旁的 `keybindings.ini`。

| 操作 | 功能 |
| --- | --- |
| A / D、W | 左右移动、跳跃 |
| 鼠标左键 / 右键 | 按下并松开，放置蓝门 / 橙门 |
| Q | 开关射门预览 |
| E | 与出口的位置、朝向匹配时过关 |
| R | 重开本关；全部通关后重新开始 |
| Esc | 暂停菜单 / 继续游戏；子页面返回菜单；改键时取消 |
| F11 / Alt+Enter | 全屏 / 窗口 |
| F1 / F2 | 头部红点 / 辅助网格 |

选关菜单可用鼠标点击，或用方向键选择、Enter 开始，PageUp / PageDown 翻页。选择关卡会重开该关，“继续游戏”保留暂停状态。

## 导入脚本与可视化回放

在选关菜单选中关卡（或进入关卡），按 **F6** 选择操作脚本。导入后从该关卡起点播放；如果文件开头有 `level ID`，则使用文件指定的源码地图 ID。回放时显示当前指令、帧进度、播放速度，以及蓝色或橙色的射门目标十字标记；普通移动和射门输入在回放期间被屏蔽。

| 按键 | 功能 |
| --- | --- |
| 空格 | 暂停 / 继续 |
| `.`（句号） | 暂停并前进一帧 |
| R | 从脚本起点重播 |
| F9 / 右上角按钮 | 隐藏 / 显示回放 UI；隐藏进度、指令、瞄准十字、关卡文字及辅助网格，保留角色红点（仍可用 F1 开关）和小型恢复按钮 |
| F7 | 退出回放，接手当前状态 |
| F6 | 导入另一份脚本 |
| Esc | 打开暂停菜单，暂停推进回放 |

失去窗口焦点会暂停回放，返回后按空格继续。脚本结束或成功过关后画面停止推进，并显示结果；R 可重播。非法脚本会显示错误行号，不替换当前游戏。最多接受 1,000,000 帧。

### 录制操作

进入关卡后按 **F10**，或在暂停菜单选择“录制”，将重开当前关卡并开始录制。再次按 F10 或点击“停止录制”结束；通关、切换关卡、导入回放或正常退出游戏时也会结束并保存。回放模式下需先按 F7 退出，才能开始录制。

脚本自动保存在程序旁的 `recordings/level-关卡ID-时间标识.txt`，保存后界面显示文件名，可按 F6 导入。只记录实际推进的逻辑帧，不录制暂停或慢速等待；支持同时移动、跳跃、重开、进入出口以及同帧多次射门，瞄准坐标保留完整精度。每份录制限当前关卡及最多 1,000,000 帧，连续相同输入自动压缩。保存失败会保留内存中的录制，可按 F10 重试；未推进任何逻辑帧时不生成空文件。

录制脚本使用兼容旧命令的新命令 `f 帧数 操作位掩码 射门数 [门编号 X Y ...]`。操作位依次为左移 1、右移 2、跳跃 4、重开 8、出口 16、跳关 32。旧的手写脚本仍可直接导入。

脚本为 UTF-8 文本（可带 BOM），每行一条指令，支持空行和 `#` 注释。每帧对应 20 毫秒：

```text
# level 使用源码 ID，不是菜单编号；省略时使用当前关卡
level 0
d 8
aw 3
s 0 260 389
z 8
e 1
```

`a/d/w` 表示按住对应键，`aw/dw` 表示同时按键，后面的整数是持续帧数；`z N` 等待，`e N` 尝试出口，`r N` 重开。`s 0 X Y` 向逻辑屏幕坐标 (X,Y) 发射蓝门，`s 1 X Y` 发射橙门，每条占一帧。坐标基于 1000×600 游戏画面，不受窗口缩放影响。上述示例仅说明格式，不保证过关。

也可从命令行直接播放，或用无窗口模式验证：

```powershell
.\build\Por2D.exe --level 16 --replay .\path\solution.txt
.\build\Por2D.exe --headless --level 16 --replay .\path\solution.txt
```

无窗口回放默认执行完整脚本；`--frames N` 可限制帧数。输出 `replay=cleared` 表示已过关，`ended` 表示脚本执行完但未过关，`partial` 表示达到帧数限制。两个版本的关卡和物理不同，操作文件不保证跨版本通用。

## 从源码构建

项目使用 C++17，Windows 构建需要带 Windows 工具链的 `g++`（例如 LLVM-MinGW）和 PowerShell。以下命令均在本 README 所在目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\build\Por2D.exe
```

脚本会生成 `build/Por2D.exe`。可通过 `-Compiler` 指定编译器，或通过 `-DebugBuild` 启用调试构建。

也可使用 CMake：

```powershell
cmake -S . -B build-cmake -DBUILD_TESTING=OFF
cmake --build build-cmake --config Release
```

窗口程序面向 Windows。需要运行回归测试时，从 [原始源码仓库](https://github.com/Scenvir/Por2D-origin) 取得 `NewlyUpdateMap.cpp`，放到本项目目录的上一级，再执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test`。测试需要该文件，单独构建游戏不需要。

常用启动参数：

```powershell
.\build\Por2D.exe --fullscreen
# --level 使用源地图 ID：5 对应菜单里的 Level 1「高山」
.\build\Por2D.exe --level 5
.\build\Por2D.exe --headless --level 5 --frames 60 --screenshot .\build\level1.bmp
.\build\Por2D.exe --window-smoke-test
```

无窗口模式用于模拟和地图截图，不展示窗口绘制的入场文字动画。

## 项目结构与背景

项目在原始地图与传送变换基础上重构，使用浮点碰撞、分步运动，以及同一帧内的角色、投影和瞄准更新。工作区的 `por2_reconstructed/` 是基础版，`Por2D/` 是四向重力版；共同功能在两版中保持同步。

- `src/levels.cpp`：地图、中文名称与评语。
- `src/portal.cpp`、`src/physics.cpp`：射线、传送变换与碰撞运动。
- `src/game.cpp`：关卡流程和游戏状态。
- `src/render.cpp`、`src/main.cpp`：画面、射门预览、窗口交互和入场动画。
- `tests/`：核心逻辑回归测试。
