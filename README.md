# Por2D 重构版

第一次游玩请阅读 [新手教程](新手教程.md)，了解操作、传送门规则和过关方法。

本版在原始 `NewlyUpdateMap.cpp` 的地图与传送变换基础上，使用浮点碰撞和同帧渲染。原文件不修改。游戏使用 Windows 原生窗口，不需要 EasyX。

## 运行与构建

双击 `build/por2.exe`，或在工作区根目录运行：

```powershell
.\por2_reconstructed\build\por2.exe
# 直接检查用户反馈的关卡：
.\por2_reconstructed\build\por2.exe --level 13
```

构建并运行回归测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\por2_reconstructed\build.ps1 -Test
```

脚本默认使用 PATH 中的 `g++`，可用 `-Compiler` 指定编译器，`-DebugBuild` 开启调试构建。本次使用 LLVM-MinGW / Clang 21.1.0，游戏静态链接 C++ 运行库。

也提供 CMake 配置，但当前环境未安装 CMake，此路径未验证：

```powershell
cmake -S por2_reconstructed -B por2_reconstructed/build-cmake
cmake --build por2_reconstructed/build-cmake --config Release
ctest --test-dir por2_reconstructed/build-cmake -C Release --output-on-failure
```

测试会包含上一级的原始文件，仅用来比较地图和有效传送变换。游戏本身不依赖原文件；独立复制项目时可用 `-DBUILD_TESTING=OFF` 仅构建游戏。非 Windows 平台只构建核心与测试。

## 操作与视觉标记

默认启动进入选关菜单。点击关卡直接开始，也可用方向键选择、Enter 开始，PageUp / PageDown 翻页。菜单按 `level.hpp` 的 `Campaign` 顺序列出正式关卡（包含 map16），末尾附实验地图 1、2。选择关卡会重新开始该关；“继续游戏”保留暂停前的状态。

F11 或 Alt+Enter 切换无边框全屏，使用窗口所在显示器。画面保持 1000×600 的比例，剩余区域留黑边，鼠标瞄准坐标随缩放转换，黑边点击不会射击。`--fullscreen` 可全屏启动；`--level ID` 可跳过菜单直接进入指定关卡。

| 操作 | 行为 |
| --- | --- |
| A / D | 左右移动，同时按下时 A 优先 |
| W | 跳跃；持续按住时落地再次触发 |
| 鼠标左键 / 右键 | 按下后释放，放置蓝门 / 橙门；穿门时只锁定身体占比更大的一侧 |
| E | 位置及身体朝向满足出口条件时过关；每次按下触发一次 |
| R | 重开当前关卡，清除全部运动、穿门和瞄准状态；通关后重新开始 |
| 左 Ctrl | 橙门存在时跳关 |
| F1 | 切换红色头部点，默认显示 |
| F2 | 切换辅助网格 |
| Esc | 打开选关菜单并暂停；已有游戏时再次按下继续 |
| F11 / Alt+Enter | 切换全屏 / 窗口 |

传送门不再显示绿色锚点。蓝门采用深蓝、蓝色、浅蓝三色，橙门采用深橙、橙色、浅黄三色，沿门自身的切向平滑过渡：**深色端 → 浅色端就是门的方向**，另一扇门相同渐变位置相互映射。门口朝向空气的一侧有亮边，用于区分墙面朝向。渐变始终显示，不受 F1 影响。

红点由本帧最终角色姿态计算。头部穿过门面时，红点显示在出口侧的投影头部；角色、投影和红点使用同一帧数据。身体和投影均按门面裁剪，不会在薄墙背面画出额外的一段身体。

当前包含地图 0–16，并保留用户的关卡修改。正式关卡顺序为 `0, 5, 6, 7, 8, 9, 10, 3, 14, 11, 12, 15, 16, 13, 4`。实验地图 1、2 没有出口，地图 1 的默认出生点为 `(200, 200)`。退出程序可点击菜单“退出”，或使用 Alt+F4。

## 本次修正

### 传送门方向

原来用射线斜率和角色姿态猜测墙面，横竖候选同时满足时还会覆盖结果。现在使用网格射线遍历，记录实际碰到的墙面法向；水平、竖直和陡斜射线使用同一套方法，拐角同时检查相邻格，取消斜率截断。

门的切向由角色“头到脚”的向量沿射线投影到墙面决定。完全垂直射击导致投影退化时，使用角色右侧方向作为确定的默认方向。放门要求连续三格可放门墙体及其外侧三格空气，不能把门装到墙体内部或覆盖另一扇门。

不再保留旧 `d_flag` 的隐式方向状态；离开门后瞄准跟随实际身体，R 重开也重新计算。此前为未加入流程的“重生”玩法保留的旧方向特性已取消。

### 浮点碰撞与穿门

- 角色位置、速度和传送映射使用 `double`；地图格坐标仍为整数。
- 用完整轴对齐碰撞箱检查实际墙格，删除旧 10 像素碰撞点网格及四向取余修正。
- 每个物理步的单轴位移不超过 0.5 像素；碰撞时二分寻找接触位置，保留沿墙滑动。它是小步积分加接触细分，不是通用刚体引擎。
- 门口不再预先挖空。身体对齐门口时，把入口侧与出口侧的身体部分分别裁剪、分别碰撞；另一侧的障碍会在身体碰到它时阻止继续进入。
- 中心跨过门面就在同一个物理步内变换位置、速度和身体朝向，之后的步使用出口坐标。取消下一帧检测和固定两帧冷却，避免高速漏传送和冷却期穿墙。
- 没有配对门、身体超出 60 像素门口、或出口局部被挡时，不能穿过实体墙。
- 意外嵌入时，在 60 像素范围寻找最近的完整可容纳位置；找不到则重开。正常运动不依靠此恢复机制穿越墙体。
- 穿门期间按两侧可见身体的实际面积判断本体归属（本游戏厚度相同，面积比例等于体积比例）。只锁定较大一侧，较小一侧可重放；各占一半时保持当前侧，完全退出后解除锁定。
- 重放另一侧时，本体位置与速度不变，投影立即移到新门。若新位置会让已伸出的身体部分嵌入墙体，则拒绝该次放置并保留旧门；不是禁止在门中射击。

重力仍朝屏幕下方，身体尺寸仍为 18 × 58 / 58 × 18，门长仍为 60。速度以像素/20ms 物理帧为单位：通常行走上限 6、重力增量 1、下落上限 20，跳跃实际初速度 -6，对应原代码 -7 后立即加 1 重力的有效值。浮点阻力不再截断小数；传送获得的大水平速度逐渐衰减，不直接削成行走速度。所有输入速度额外限制在每轴 ±1000，约束异常状态的步数。

由于碰撞和移动规则已经有意改进，不再要求运动逐帧复刻旧版。跳跃手感、惯性和极限间隙处的表现会有所不同，需要试玩核对各关难度。

### 帧执行顺序

`输入 → 浮点运动/碰撞/传送 → 从最终身体计算投影和头点 → 射击 → 刷新视图 → 渲染`

射线起点与红点取自同一姿态，不再使用物理更新前的头坐标。新放置的门会立即显示，并在下一次物理推进中生效。

穿门时的每条射击消息都会重新计算占比、锁定对象和头点。若头部在可重放的另一侧，射线从那里的头部发出；该门重放后，下一条消息使用新头点。射线保留发射瞬间的起点，红点始终显示最终位置。

### 与原版锁定逻辑的关系

`NewlyUpdateMap.cpp` 的蓝门条件是 `canshoot && is_in_portal`（禁止 `is_in_portal == 0`），橙门条件是 `canshoot && is_in_portal != 1`。它的设计意图就是只锁定本体所在门，另一扇门可以射击。对于本游戏的矩形身体，中心跨面即对应面积占比超过一半。

但原版传送时只修改位置、速度和姿态，没有立即修改 `is_in_portal`。测试实际执行原函数后发现，蓝门传到橙门的当帧仍可能保留 0，锁错一帧。本版直接按当前面积决定锁定对象，消除了这个时序差异。

## 模块

| 文件 | 责任 |
| --- | --- |
| `include/por2/types.hpp` | 浮点向量、整数格坐标、角色与矩形 |
| `src/levels.cpp` | 原地图数据 |
| `src/portal.cpp` | 墙面射线、放门方向、坐标/速度/身体变换和门面裁剪 |
| `src/physics.cpp` | 实体碰撞、分步移动、同步穿门和异常恢复 |
| `src/game.cpp` | 输入、关卡流程和当前帧视图 |
| `src/render.cpp` | 身体与投影裁剪、三色门渐变、同帧红点、BMP 导出 |
| `src/main.cpp` | 原生窗口与消息处理 |
| `tests/tests.cpp` | 几何不变量、具体故障场景和随机输入回归 |

## 验证

当前 7 组核心测试通过，共 **776,164 项断言**，包括：

- 17 张可编辑地图的数据有效性、64 种传送变换与原版对照；浮点往返还原、速度大小和身体裁剪面积检查。
- 墙面朝向、门切向、垂直/陡斜/拐角射线、墙面外侧可用性。
- 高速撞墙、嵌入恢复、`map13` 竖井/下部立柱/横向通道及下方地面门到侧墙门的实际路径。
- 64 种门对 × 4 种身体方向，共 256 个从门外进入并完成传送的场景。
- 出口被挡、入口不对齐，以及身体完全退出后的状态解除。
- 门颜色随方向反转、移除绿点、包含实际传送的同帧红点检查。
- 256 种门对/姿态下的本体侧锁定、另一侧重放、50/50 边界、跨面当帧解锁；从投影头部连续射击、头点恰好在门面上的射击，以及新投影碰撞时的原子回滚。
- 16 张地图共 48,000 帧随机输入，每帧检查有效位置与非穿透条件。
- 正式关卡顺序、跳关条件、最终完成和重新开始。
