Por2D / 地图编辑器

基础版 · 50 × 30 · 本地离线编辑

画笔 · 数字键 1–5

选择元素

拖出矩形，选中范围内的方块及相交的出生点、出口；拖动蓝色选中元素整体移动。在其他位置拖动重新框选。Esc 取消拖动或清除选择。移动不能越界或覆盖其他方块，支持撤销 / 重做。

绘制方式

矩形：选方块后拖动至对角，松开填充；右键矩形擦除方块。Esc 取消。出生点与过关点仍为单点放置。

身体朝向

选出生点或过关点后，点击网格放置。朝向选择会更新已选标记。出口的三角箭头及头端横线表示过关时要求的头部方向，不是重力方向。每类标记仅有一个；右键清除标记或方块。

地图信息

格坐标原点在左上，X 向右，Y 向下。每格为 20×20 游戏像素。

移动鼠标查看格坐标与像素坐标
选择画笔，在网格上按住左键拖动绘制。
使用说明与保存格式

左键绘制，右键擦除；出生点与过关点按角色实际大小显示（18×58 或 58×18 像素），箭头代表头部朝向。Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做，Ctrl+S 下载地图。

“保存地图 JSON”下载可再次打开的编辑器文件。把下载的 JSON 文件复制到游戏旁的 levels 文件夹，重新启动游戏后，即可在关卡选择末尾找到“自定义”地图。编辑器不依赖网络，也不会自动保存，关闭或刷新页面前请先保存。

地图检查会提示标记缺失、身体与墙重叠或触碰边界；不保证关卡一定可解。空白地图可以先在底部绘制地板，再将出生点放在地板上方三格的位置。
